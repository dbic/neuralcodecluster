# Presidential Cluster on Breaking the Neural Code

Website for Dartmouth's Presidential Cluster on Breaking the Neural Code.

**Live site: https://neenadzur.github.io/clusterwebsite/**

The site covers the cluster's mission and goals, priority research areas, a directory of neuroscience labs across Dartmouth, the people behind the cluster, and past and upcoming events.

## About this repository

`index.html` is a single-file copy of the site. The live site is maintained in [neenadzur/clusterwebsite](https://github.com/neenadzur/clusterwebsite), and this copy may lag behind it.
